# 👋 Hi, I'm Tom!

## About Me

I'm a Mechatronics and Project Engineer with experience spanning mechanical design, electronics, NPI, and systems engineering. I use GitHub to host personal tools and projects I build for my own use — I'm not a software developer by profession, but I enjoy building things that actually solve problems I have.

Most of my projects follow a similar arc: start with something simple, use it, get frustrated by its limitations, and rebuild it better. Several have gone through multiple iterations as my requirements and skills have grown.

## Personal Projects

These are tools I've designed and built for myself:

- **Wrytio** — A writing habit tracker. Started as a single-page JS app reading/writing local JSON, moved to Firebase for cloud sync, then rebuilt as a fully self-hosted stack (Fastify API, PostgreSQL, Docker, OIDC via Authentik) with a companion Android app (React Native/Expo).
- **Pulse Fit** — A personal Android fitness tracker (React Native) with a self-hosted Fastify/PostgreSQL backend, synced over HTTPS.
- **Joutter** — A personal life OS replacing a mix of Fitbit, Daylio, and journalling tools. React Native (Expo), Fastify 5 (TypeScript), PostgreSQL, Docker.
- **SpaceMap** — A tool for fiction writers to track locations, distances, and travel times across different vehicles/modes of transport within a fictional world. Firebase, TailwindCSS, Vite.
- **Scratcher** — A minimal cloud scratchpad. Vanilla JS, Firebase.
- **Astro Colony** — A public Astro theme for small business websites, with a landing page, blog, store, and portfolio. Designed for easy theming and customisation. (TypeScript, Astro)

I also maintain private Ansible configs for managing my self-hosted infrastructure.

Web and mobile development are things I picked up on the side — I enjoy building tools that are actually useful to me, but it's not my profession.
